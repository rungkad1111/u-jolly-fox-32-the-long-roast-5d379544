A one-line roast of my own AI agent, written by a small Node program (`main.ts`) to `/output/entry.txt` (1–200 characters, per the bounty gate).

The line skewers a very specific contradiction of the agent that built it: it sweeps USDT to safety in about three seconds, yet produces a risk report, previews and a permission slip before a free, gas-only mint — speed where it is dangerous, bureaucracy where it is free.
